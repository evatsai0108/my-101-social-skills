# 特教教師課前人工審核與個別化檢核清單

> 任何 AI 產出的社交課程，都必須通過特教老師對「個別學生身心狀況與最近行為事件」的現場專業判斷。

## 一、 安全與情緒風險把關
- [ ] **觸發點防範**：本週挑選的演練情境（如桌遊輸贏、被拒絕），是否會踩到特定情障學生的近期急性地雷？
- [ ] **冷靜空間準備**：教室角落的「冷靜角」（Cool-down zone）是否保持暢通，且有準備好個別學生適用的減壓工具（如減壓球、計時器）？
- [ ] **安全界線**：是否已向所有學生重申「嚴禁任何肢體接觸攻擊、嘲笑或大聲喧鬧」？

## 二、 障別個別化調整確認
- [ ] **自閉症 (ASD) 學生**：
  - [ ] 是否已備妥每一步驟的「視覺結構流程圖」？
  - [ ] 是否已給予課堂流程預告（何時結束、會玩什麼桌遊）？
- [ ] **學習障礙 (LD) 學生**：
  - [ ] 課堂上是否有過多純文字閱讀負擔？（若有，是否已改為圖示或口頭提示）？
  - [ ] 是否提供了句型開頭的口語提示卡？
- [ ] **情緒障礙 (EBD) 學生**：
  - [ ] 是否安排了具備包容力、較穩定的同學作為演練搭檔？
  - [ ] 是否已和普通班導師了解該生當天的出門狀況與情緒基線？

## 三、 類化與親師合作
- [ ] **普通班類化卡**：本週學會的「魔法我訊息」或「加入遊戲三步驟」，是否已印製迷你口袋小卡，交代給普通班導師於下課時給予即時增強？
- [ ] **家長溝通聯絡**：是否在聯絡簿或特教日誌中，請家長於家庭情境中同步給予肯定？
